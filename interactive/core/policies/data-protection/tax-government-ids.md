# Tax / Government IDs
<!-- tier: minimal -->

This category covers VAT registration numbers, the tax identifications held against a business partner, and tax documents that are specific to one country — Brazil NF-e among them.

| Table | Description | Why |
|-------|-------------|-----|
| DFKKBPTAXNUM | BP tax numbers (FI-CA) | Tax IDs |
| TFKTAXNUMTYPE | Tax number types | Not sensitive by itself, but linked to what is |
| J_1BTXIC3 / J_1BNFDOC | Brazil tax/NF data | Regional tax PII |
| KNAS | Customer VAT registration | VAT / tax IDs |
| LFAS | Vendor VAT registration | VAT / tax IDs |
| BUT0TX | BP tax numbers | BP tax IDs |
