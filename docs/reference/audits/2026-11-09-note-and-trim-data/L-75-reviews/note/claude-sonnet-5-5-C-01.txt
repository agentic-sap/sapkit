**과제 지시 때문에 결함으로 세지 않은 항목**
- 메인 프로그램 템플릿, INCLUDE 구성, TOP include 규칙: 과제가 "no INCLUDEs"를 요구함
- text-pool R/I/S 2개 언어 작성: 과제가 "no separate text pool"을 요구함
- 객체명 ZJUDGE_C01의 Z{MODULE}R{NN} 규약: 과제가 이름을 지정함

**문제없음으로 확인한 항목**
- SELECT 필드 목록이 명시되어 있음
- 명시적으로 타입 지정한 itab을 사용함
- 7.58 범위 안의 문법만 사용함
- `abap_true` 사용이 올바름
- ORDER BY와 UP TO를 함께 써서 결과가 결정적임
- 빈 결과일 때 정보 메시지를 띄움
