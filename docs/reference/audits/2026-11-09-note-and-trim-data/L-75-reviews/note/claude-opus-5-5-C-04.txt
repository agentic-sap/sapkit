**제외·참고 (지적하지 않음)**
- **INCLUDE 구조 / 메인 프로그램 템플릿 / TOP include:** 과제가 "no INCLUDEs, one file"을 명시했으므로 정당한 편차로 본다.
- **OOP 템플릿 대조 항목:** Paradigm = Procedural이라 적용하지 않았다.
- **오브젝트명 `ZJUDGE_C04`:** `Z{MODULE}R{NN}` 규칙과 다르지만 과제가 지정한 이름이다.
- **검사기가 이미 보고한 항목은 재기재하지 않았다:**
  - `lo_*`/`lx_*` 명명 경고 (89–92)
  - 50행 `"SYMBOLS"` 경고
  - double_space 10건 (25, 29, 51, 57, 73, 80, 89, 91, 92, 96)
  - 참고로 50행 경고는 `FIELD-SYMBOLS` 키워드를 잘못 토큰화한 오탐으로 보이고, double_space 건들은 정렬용 공백이다. 결과는 판정대로 두었다.
- **릴리스 위반 없음:** 7.58보다 새로운 문법은 쓰이지 않았다.
