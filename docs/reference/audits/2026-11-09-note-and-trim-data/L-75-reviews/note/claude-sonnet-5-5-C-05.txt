## 제외한 항목과 근거

- **검사기 결과 수용:** analyze가 낸 `double_space` 9건(20, 25, 51, 58, 63, 67, 73, 86, 96)은 그대로 인정하고 위 목록에 다시 올리지 않았습니다.
- **INCLUDE 구조 / 템플릿 불일치:** 과제가 "INCLUDE 없이 단일 파일"을 요구했으므로 정당한 예외로 보았습니다.
- **오브젝트명 `ZJUDGE_C05`:** 과제가 지정한 이름이라 `Z{MODULE}R{NN}` 규칙을 적용하지 않았습니다.
- **릴리스 7.02 위반:** 없습니다. 인라인 선언, `NEW`/`VALUE`, 문자열 템플릿, 테이블 식을 쓰지 않았고 `RETURN`, `LEFT-JUSTIFIED`, `LOOP … WHERE`는 7.02에서 사용 가능합니다.
- **OOP 그룹 및 OOP 템플릿 항목:** 패러다임이 Procedural이라 적용하지 않았습니다.
