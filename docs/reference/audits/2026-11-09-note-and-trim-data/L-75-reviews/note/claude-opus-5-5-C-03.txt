**참고 (어긋남으로 세지 않은 항목)**
- 19, 21, 24행의 double_space는 검사기가 이미 보고했으므로 여기서 다시 올리지 않았다.
- FM 이름 `Z_JUDGE_C03_…`는 하우스 패턴 `Z{MODULE}FM_{PURPOSE}`와 다르다. 다만 과제가 이름을 지정했으므로 작성자의 위반이 아니다.
- 인라인 시그니처(1–9행)는 규칙에 맞다. MAKT 조회는 전체 키(matnr + spras)를 쓰고, 두 오류 조건도 과제 요구대로 구분되어 있다.
- 과제 범위가 FM만이므로 Procedural 메인 프로그램 템플릿과 OOP 템플릿 항목은 해당하지 않는다.
