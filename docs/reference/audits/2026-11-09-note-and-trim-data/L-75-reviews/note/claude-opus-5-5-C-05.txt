**제외하거나 판정을 보류한 항목**

- **검사기 판정 수용:** 검사기가 지적한 double_space 6건(39, 40, 69, 76, 95, 103행)은 그 판정을 그대로 받아들이고 다시 올리지 않았다.
- **OOP 템플릿 대조:** Paradigm이 Procedural이므로 적용하지 않았다.
- **include 구조·TOP include 규칙:** 과제가 "INCLUDE 없이 파일 하나"를 명시했으므로, main-program 템플릿·include 구조·TOP include 규칙에서 벗어난 부분은 과제 지시로 정당화된다고 보고 지적하지 않았다.
- **Text pool 규칙(R/I/S 텍스트, logon 언어와 'E' 두 번 기록, S 텍스트 offset 8):** 산출물이 소스 파일 하나뿐이라 검증할 수 없다. 8–16행 주석에 예정된 텍스트가 적혀 있을 뿐, 실제 등록 여부는 확인해야 한다.
- **릴리스 위반 여부:** 7.40 이후 구문(인라인 선언, VALUE/NEW, 문자열 템플릿, 테이블 식 등)은 발견되지 않았다. 7.02 기준으로 위반 없음이다.
