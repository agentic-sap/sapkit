참고 사항 (어긋남 목록과 별도)

- **메인 프로그램 템플릿 대조는 못 했습니다.** `clean-code.md`와 `clean-code-procedural.md`는 읽었지만 `knowledge/abap/templates/procedural-sample/main-program.abap` 파일은 이 작업공간에 없습니다. 그래서 INCLUDE 순서와 이벤트 블록 배치는 확인하지 못했습니다. 다만 과제가 "no INCLUDEs, 단일 파일"을 명시했으므로 INCLUDE 구조와 TOP include 규칙에서 벗어난 것은 과제가 정한 것이고, MAJOR 지적 대상이 아니라고 판단했습니다. 같은 이유로 "DATA는 TOP include에만" 규칙도 해당 없음으로 처리했습니다.
- **검사기의 `double_space` 3건(14, 19, 68줄)은 오탐입니다.** 정렬을 위한 공백이고, 일관된 정렬은 §8 서식 규칙이 오히려 요구하는 것입니다.
- **충족한 항목:**
  - `SELECT *` 없음
  - LOOP 안의 SELECT 없음
  - SELECT 뒤에 sy-subrc 확인함(55줄)
  - INTO 대상이 명시적인 타입의 테이블임
  - 집계 결과를 순차로만 읽으므로 보조 키는 필요 없음
  - FORM 파라미터에 모두 타입이 있음
  - USING(입력)과 CHANGING(출력)을 맞게 씀
  - boolean USING 파라미터 없음
  - 주석 처리된 코드나 디버그 문 없음
  - EXIT, STOP을 오류 처리에 쓰지 않음
  - 비율 연산이나 대사(reconciliation) 로직 없음
  - STRING 리터럴 대상 없음. `'…'(nnn)`은 텍스트 심볼이라 해당 없음
