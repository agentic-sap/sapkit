**위반 아님 / 판정 메모**

- **주 프로그램 구조:** 템플릿 `knowledge/abap/templates/procedural-sample/main-program.abap`이 이 위치에 없어서 대조하지 못했음. 과제가 "INCLUDE 없이 단일 파일"을 명시했으므로 INCLUDE를 쓰지 않은 구조는 정당하다고 봄. spec.md가 없으니 과제 지시문을 spec으로 삼았음.
- **문제없음:**
  - SELECT 필드를 명시적으로 나열했고, LOOP 안 SELECT가 없음.
  - 타입이 지정된 테이블에 SELECT함.
  - 7.40 이후 문법을 쓰지 않음.
  - 주석 처리된 코드나 디버그 문장이 없음.
  - 비율 연산이 없음.
  - ABAP_BOOL로 선언하고 abap_true / abap_false와 비교함. 7.02에는 XSDBOOL이 없음.
- **해당 없음:**
  - KNA1은 마스터 테이블이라 COUNT(*) 사전 점검과 보조키 규칙의 적용 대상이 아님.
  - 문자열 리터럴이 없고 텍스트 요소를 사용함.
  - SORT에 BY가 있음.
  - PBO/PAI나 화면에 묶인 FORM이 없음.
  - 과제가 테스트를 요구하지 않음.
- **80줄 `RETURN`:** 메시지를 출력한 뒤 빠져나가는 가드절이라 "EXIT/STOP으로 오류 처리 대체" 금지에 걸리지 않음.
- **검사기 `double_space` 6건:**
  - 39, 40, 76, 95줄은 정렬용 공백이고 일관되게 맞춰져 있음.
  - 69, 103줄은 `ENDFORM.` 뒤 끝 주석 앞의 공백임.
  - 둘 다 §8 위반이 아니라 오탐으로 판정함.
- **§8 체크리스트 밖 참고 사항:** 아래는 `clean-code.md`에는 있지만 §8 항목은 아니어서 결과 목록에 넣지 않았음.
  - `lv_first`는 불리언 이름 규칙에 따라 `lv_is_first`가 되어야 함.
  - 1–17줄 배너 주석
  - AUTHORITY-CHECK가 없음
