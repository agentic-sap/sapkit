== 검색 문장 정본 (모든 상담가 공통 · 영어 · 폴더 경로만 바뀐다) ==

[M] 모듈 (C-1) — <M> = 그 상담가의 모듈 폴더 이름(FI · CO · SD · MM · PP · PM · PS · QM · WM · TM · TR · HCM · BW · Ariba)
Search the `../knowledge/modules/<M>/` folder with the key terms of the question and read only the lines that match — do not load its files whole. Its reference files are tables in which each row is a complete entry and the System column carries the ECC/S4HANA compatibility; follow a matched line as the authoritative reference.

[C] 공통 (C-2) — [M]과 같은 문장, 폴더만 common
Search the `../knowledge/modules/common/` folder with the key terms of the question and read only the lines that match — do not load its files whole. Its reference files are tables in which each row is a complete entry and the System column carries the ECC/S4HANA compatibility; follow a matched line as the authoritative reference.

[N] 나라·업종 (C-3) — <areas> = 원래 문장에 있던 영역 예시. 원래 예시가 없던 Triggered: 줄에는 기본값 "tax, e-invoicing, statutory reporting, industry business processes, and the like"
Search the configured country / industry folder (`../knowledge/country/` · `../knowledge/industry/`) only when the question falls in that area (<areas>) — search it with the configured country code or industry key plus the key terms of the question, read only the lines that match, and follow a matched line as the authoritative reference.

살린 고유한 뜻: 「with authority」 → 「follow a matched line as the authoritative reference」 · 「its System column carries the ECC/S4HANA compatibility」 → [M]/[C] 안에 · 영역 예시 → [N]의 <areas> · 나라/업종 결정 순서와 「미설정이면 사용자에게 묻는다」 문장은 원문 그대로 유지(여러 나라면 「load each file」 → 「search for each one」).
파일 이름(tcodes.md 등)은 문장에 쓰지 않았다. 폴더 경로만 백틱.
