판J — 하네스 필요성 검토 (harness necessity review) 자료 폴더
=====================================================================

이 폴더는 2026-11-05 착수한 판J(D-156)의 **측정 자료 폴더**다. 판J의 각 과업(T0~T12)이
만든 원자료·표·레시피·카나리아 응답을 한 자리에 모은다. 판단(결론)은 여기 두지 않는다 —
결론은 판J의 감사 문서와 결정 로그(D-번호)가 가진다. 여기에는 **측정한 것·관찰한 것**만 둔다.

새 파일은 자기 과업의 접두어로 시작한다. 접두어 뒤의 이름은 자유이되 내용을 말해야 한다
(예: 50-blind-run-log.txt).

이 폴더에 .md 파일을 두지 않는다 (중요)
---------------------------------------
이유: 공방 문서 게이트 `scripts/check-wiki.mjs`(콜드 층 위키 구조 검사)가 **고아 검출**의
분모를 `docs/reference/**/*.md` 전체로 잡는다 — 제외는 `handoff-archive/`·`run-archive/`
두 아카이브 디렉터리뿐이다. 이 폴더의 .md는 위키 어디에서도 링크되지 않으므로 전부
「고아」로 잡혀 게이트가 red가 된다. 그래서 이 폴더의 모든 파일은 .md가 아닌 확장자를 쓴다.

허용 확장자: .txt  .json  .csv  .abap  .mjs  .ps1
(다른 확장자가 필요하면 .md만 아니면 되지만, 위 여섯 안에서 고르는 것을 기본으로 한다.)

비밀·식별 정보 금지
-------------------
이 폴더 어디에도 다음을 적지 않는다:
  - 고객사 이름 · SAP 시스템 ID(SID) · 호스트명 · URL · 클라이언트 번호 · 사용자 ID
  - 자격증명 · 토큰 · 키 · sap.env 내용
다른 프로젝트 · 프로파일의 이름은 스위치 표(00)에만 둔다 — 머리의 관찰 대상 줄과 「소유자 설정값」 열이다.
그 열은 on/off · 이름(프로파일 별칭·프로젝트 폴더명) · tier/surface 값만 적는다. 다른 파일에서는 사고 출처
코드(P1~P6 — 40-sources)나 「소유자 프로젝트 갑 · 을」(20 · summary.json — P 코드와 짝짓지 않은 따로 된 표시)로
부른다. 레포 밖 작업 공간의 절대 경로도 적지 않는다(20-measure-tokens.mjs는 그 경로를 인자로만 받는다).
블라인드 실행의 원 이벤트 스트림(세션 id·로컬 경로 포함)은 커밋하지 않고, 추출 요약(…-events.txt)만 둔다.

판 준비 문서와 작업 폴더 (2026-11-06 · 마감 리뷰 회수 — 93 §1 5)
--------------------------------------------------------------
  자료 파일 몇 곳(83 · 20 · 30 · 11 · 40 · 60 · 90)은 근거를 「spec」 뒤에 영문 한 글자와 숫자를 붙인 꼬리표로 적었다.
  판을 준비할 때 쓴 작업 문서(레포에 커밋하지 않는다)의 절이라, 레포만 가진 독자는 찾아갈 수 없다. 원자료는 기록이라
  고치지 않았고, 커밋된 같은 내용의 자리를 여기 적는다.
    A 목적과 동기 · D 척도와 기준선    → 감사 문서 §1
    B 불변                            → D-156 「바꾸지 않는 것」 · 「재심 제외 셋」
    C 층 목록 · 규약 갈래             → 감사 문서 §1.7 · 01
    E 측정(사전 준비 + 다섯)과 그 선  → 감사 문서 §2.1 · §2.2
    F 판정 계약                       → 감사 문서 §2.3
    G 산출물 · H 완료 조건            → 감사 문서 머리 · D-157(마감 기록)
    I 범위 밖                         → 감사 문서 §7.9
    J 결정의 이유                     → D-156 「소유자 결정 열」 · 「메인이 근거로 정한 것」
  60의 「워크트리·브랜치」 줄과 20-tokens-raw의 세션 시작 훅 출력에 남은 작업 폴더 경로 · 작업 가지 이름도 같은
  성격이다 — 판이 끝나면 지워지는 자리다. 훅 출력은 측정 입력 그대로라 두었다.
