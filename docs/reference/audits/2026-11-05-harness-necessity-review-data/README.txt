판J — 하네스 필요성 검토 (harness necessity review) 자료 폴더
=====================================================================

이 폴더는 2026-11-05 착수한 판J(D-156)의 **측정 자료 폴더**다. 판J의 각 과업(T0~T12)이
만든 원자료·표·레시피·카나리아 응답을 한 자리에 모은다. 판단(결론)은 여기 두지 않는다 —
결론은 판J의 감사 문서와 결정 로그(D-번호)가 가진다. 여기에는 **측정한 것·관찰한 것**만 둔다.

(예: 50-blind-run-log.txt).

이 폴더에 .md 파일을 두지 않는다 (중요)
---------------------------------------
이유: 공방 문서 게이트 `scripts/check-wiki.mjs`(콜드 층 위키 구조 검사)가 **고아 검출**의
분모를 `docs/reference/**/*.md` 전체로 잡는다 — 제외는 `handoff-archive/`·`run-archive/`
두 아카이브 디렉터리뿐이다. 이 폴더의 .md는 위키 어디에서도 링크되지 않으므로 전부
「고아」로 잡혀 게이트가 red가 된다. 그래서 이 폴더의 모든 파일은 .md가 아닌 확장자를 쓴다.

허용 확장자: .txt  .json  .csv  .abap  .mjs  .ps1
(다른 확장자가 필요하면 .md만 아니면 되지만, 위 여섯 안에서 고르는 것을 기본으로 한다.)

비밀·식별 정보 금지
-------------------
이 폴더 어디에도 다음을 적지 않는다:
  - 고객사 이름 · SAP 시스템 ID(SID) · 호스트명 · URL · 클라이언트 번호 · 사용자 ID
  - 자격증명 · 토큰 · 키 · sap.env 내용
스위치 표(00)의 「소유자 설정값」 열은 on/off · 이름(프로파일 별칭·프로젝트 폴더명) ·
tier/surface 값만 적는다. 블라인드 실행의 원 이벤트 스트림(세션 id·로컬 경로 포함)은
커밋하지 않고, 추출 요약(…-events.txt)만 둔다.

가림과 예외 (2026-11-06 · 리뷰 회수 때 적용 — 91 §3 O4 · O5)
------------------------------------------------------------
  - 로컬 경로 속 계정 이름 → <usr> (글자 수 같음). 카나리아 원응답 · 실행 기록 · 재시도 기록 10파일 75곳.
    가림은 그 한 조각만 바꿨고 나머지 바이트는 그대로다(집계 입력 파일은 건드리지 않았다).
  - Codex CLI 오류문이 남긴 한도 안내 웹 주소 → <url>. 3파일 96곳.
  - 예외 둘 — 증거라서 두었다:
      · tools-list 캡처(20의 측정 입력)에 든 JSON 스키마 메타스키마 id(json-schema.org) — 도구 등록점이 내보낸 바이트
        그대로가 측정 대상이다
      · 81의 SAP 공식 도움말 인용 — 프로토콜 표기 없이 도메인과 경로만 적었다(팩 감사의 근거)
  - 기준선 서버의 공개 패키지 이름(20 · summary.json)은 사용자 ID가 아니라 공개 이름이라 두었다.
