**활성화 요건:** `strict ( 2 )`에서는 루트 엔티티에 `authorization master ( global / instance )` 선언(자식은 `authorization dependent by`)이 필수입니다. 앵커 CDS 뷰는 DDIC 기반 `define view`가 아닌 `define root view entity`(CDS 뷰 엔티티)여야 합니다.

**strict를 빼면:** 이런 엄격 구문 검사가 적용되지 않아, 누락이나 레거시 구문이 있어도 오류 없이(대개 경고만 나고) 활성화됩니다. 다만 향후 호환성과 모범 사례는 보장되지 않습니다.
