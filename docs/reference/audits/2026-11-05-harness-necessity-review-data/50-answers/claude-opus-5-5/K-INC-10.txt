**XFELD/X 도메인 CHAR(1)** → SADL/CDS·RAP 기반 OData에서 **Edm.Boolean**으로 매핑됩니다('X'↔true, ' '↔false 자동 변환). 따라서 `$filter=Flag eq true`처럼 따옴표 없이 boolean 리터럴로 씁니다.
**일반 CHAR(1) 도메인** → **Edm.String (MaxLength=1)**이며 `$filter=Field eq 'X'`처럼 문자열 리터럴로 비교합니다. 단, SEGW 수동 모델은 기본이 Edm.String이라 boolean으로 쓰려면 직접 매핑·변환해야 합니다.
