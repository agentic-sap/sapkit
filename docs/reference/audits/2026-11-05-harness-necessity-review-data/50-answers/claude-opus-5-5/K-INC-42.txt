**도구:** 보통 `GetClassInclude`(include type = `implementations`, ADT 경로 `/sap/bc/adt/oo/classes/<클래스>/includes/implementations`) 같은 클래스 include 조회 도구로 CCIMP를 읽습니다. 서버에 따라 `GetInclude`에 `<클래스명>====CCIMP` 형태로 넘기는 방식도 있습니다.

**안 보일 때:** readonly 도구 목록에 없으면 이 서버에서는 CCIMP 조회가 지원되지 않는다고 보고, 그 한계를 명시해 보고합니다. 로컬 핸들러 내용을 추측해 만들어내지 않습니다. 이 답은 기억에 근거한 것이라, 실제 도구 이름은 서버의 도구 목록에서 확인해야 합니다.
