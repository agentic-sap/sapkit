**원인:** V4 서비스 발행(ADT Publish 또는 `/IWFND/V4_ADMIN`의 서비스 그룹 Publish)은 클라이언트 종속 Gateway 커스터마이징을 기록합니다. 그런데 현재 클라이언트는 SCC4에서 해당 커스터마이징 변경이 막혀 있습니다(No changes allowed 또는 생산/비개발 클라이언트 설정).

**정공법:** 커스터마이징 변경이 허용된 개발/커스터마이징 클라이언트(SCC4 "Automatic recording of changes")에서 발행해 Customizing request에 기록하고, 이를 QAS/PRD로 이관(transport)합니다. 운영 클라이언트의 SCC4를 임시로 열어 직접 발행하는 것은 우회책이라 권장되지 않습니다.
