**ADT(UpdateFunctionModule)**: 시그니처를 `FUNCTION z_fm IMPORTING VALUE(iv_x) TYPE string EXPORTING ... .`처럼 FUNCTION 문 안에 실제 코드로 씁니다. **abapGit 미러**: `.abap` 파일은 `FUNCTION z_fm.` 뒤에 `*"Local Interface:` 주석 블록만 있고, 실제 시그니처는 `.fugr.xml`(IMPORTING/EXPORTING 테이블)에 들어 있습니다.

**바꿔 넣으면**: abapGit 형식을 ADT에 쓰면 주석 블록은 무시되어 파라미터가 사라집니다(파라미터를 참조하는 곳은 구문 오류). 반대로 ADT 형식을 abapGit 소스에 넣으면 클래식 FM 소스에서 허용되지 않는 FUNCTION 문이 되어 구문 오류나 활성화 실패가 나고, XML 시그니처와도 어긋납니다.
