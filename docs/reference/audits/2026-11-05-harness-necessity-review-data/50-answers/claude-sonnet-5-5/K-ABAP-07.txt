With `value_org = 'S'` (structured), the row type of `value_tab` should reference a flat ABAP Dictionary structure or table (e.g. `TYPE TABLE OF <ddic_struc>`). The function builds the list's columns from that structure's DDIC field definitions, and a purely local, non-DDIC type can leave the list empty or without field info.
