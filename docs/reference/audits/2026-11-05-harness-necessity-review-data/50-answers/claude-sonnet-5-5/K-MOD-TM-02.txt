I believe the Tracking and Tracing Monitor is reached via the SAP Event Management transactions (the `/SAPTRX/` namespace, e.g. `/SAPTRX/EH_MON` for the event handler monitor). In S/4HANA TM it is also available from the SAP Easy Access / Fiori menu rather than a dedicated TM-specific T-code. Please check the exact code in your system with `/n` plus the menu path or the `SEARCH_SAP_MENU` transaction.
