`@UI.facet`는 엔티티(뷰) 레벨, 즉 DDLX의 `annotate view ... with` 바로 아래(요소 앞)에만 둘 수 있고, 개별 요소(필드) 위에는 둘 수 없습니다. 'wrong scope' 거부는 이 어노테이션을 허용되지 않는 범위(예: 요소 레벨)에 붙였다는 뜻으로, 해당 어노테이션의 허용 스코프(Entity)와 사용 위치가 맞지 않는다는 오류입니다.

(참고로 `@UI.facet`의 각 항목이 참조하는 `@UI.lineItem`, `@UI.fieldGroup` 등은 요소 레벨에 두며, 이는 기억에 의존한 답변이라 실제 시스템 버전에서 확인이 필요합니다.)
