`encoding`은 `abap_encoding`(= `string`) 타입 파라미터라서, CHAR4 도메인 타입의 상수를 넘기면 타입이 맞지 않아 구문 오류(또는 호환되지 않는 타입 불일치)가 납니다. 코드페이지 이름을 문자열 리터럴이나 `abap_encoding` 타입 변수로 넘기세요. 예: `encoding = '4110'`(UTF-8) 대신 `encoding = `UTF-8`` 또는 `cl_abap_codepage=>sap_to_http( '4110' )` 결과(string)를 사용하거나, `DATA(lv_enc) = CONV abap_encoding( 'UTF-8' ).`로 변환해 전달합니다.

(참고: 정확한 타입 정의는 시스템 버전에 따라 다를 수 있으니 SE24에서 확인하세요.)
