abapGit은 오프라인 레포의 ZIP을 "전체 스냅샷"으로 간주하므로, 신규·변경분만 담긴 ZIP을 pull하면 ZIP에 없는 기존 오브젝트는 레포에서 사라진 것으로 인식됩니다. 그 결과 pull 시 해당 오브젝트들이 시스템에서 삭제 대상(Deletion)으로 잡힐 수 있어 위험하며, 변경분만 반영하려면 기존 전체 ZIP에 병합해서 import하거나 별도 패키지/온라인 레포로 관리해야 합니다.

(참고: 실제 삭제 여부는 pull 시 표시되는 오브젝트 목록과 설정에 따라 달라지므로, 적용 전 확인 화면에서 삭제 항목을 반드시 점검하세요.)
