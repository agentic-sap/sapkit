"MCP UpdateTable"의 정확한 동작은 제가 확실히 아는 바가 없어서 단정하기 어렵습니다. 다만 일반적인 SAP(ABAP Dictionary) 동작 기준으로는, 데이터가 있는 테이블의 필드 길이 축소나 필드 삭제는 활성화 시 테이블 변환(conversion)이 필요하고, 길이 축소는 데이터 잘림/변환 오류, 필드 삭제는 해당 컬럼 데이터 손실 위험이 있으므로 사전에 백업·검증이 필요합니다.

특정 MCP 서버의 UpdateTable이 이를 막는지(오류 반환), 경고만 하는지, 그대로 적용하는지는 해당 도구 문서나 실제 테스트로 확인하셔야 합니다.
