MIGO posts through the **MB_CREATE_GOODS_MOVEMENT** function module (the core of the MB_POST_GOODS_MOVEMENT chain), which `BAPI_GOODSMVT_CREATE` itself wraps. MIGO's own posting goes through the class `CL_MMIM_...`/`MB_POST_GOODS_MOVEMENT` update logic, so if you want the lowest-level internal posting routine, use **MB_POST_GOODS_MOVEMENT** (called after `MB_CREATE_GOODS_MOVEMENT` prepares the data).
