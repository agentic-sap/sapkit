`{ update; }`만 주면 이미 존재하는 인스턴스가 변경될 때만 실행되고, 같은 트랜잭션에서 새로 생성(create)된 인스턴스에는 트리거되지 않습니다. create 시에도 돌리려면 `{ create; update; }`처럼 둘 다 지정하고, 필드 단위는 `{ field F1; }` 또는 `{ update; field F1; }` 형태로 좁힙니다.

create를 노출하지 않는 BO(예: `create`가 없고 update만 있는 BO나 하위 엔티티)에서는 create 트리거를 쓸 수 없으니(정의되지 않은 오퍼레이션이라 구문 오류), `{ update; }`만 지정하는 것이 정상적인 사용법입니다. 이런 BO는 기존 데이터를 변경하는 경로만 있으므로 update 트리거만으로 충분합니다. 이 내용은 기억에 의존한 것이라 정확한 문법은 사용 중인 릴리스에서 확인해 보세요.
