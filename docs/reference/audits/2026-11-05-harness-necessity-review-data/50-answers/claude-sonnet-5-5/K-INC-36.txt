FM이 예외를 하나도 선언하지 않았어도 `EXCEPTIONS OTHERS = 1`을 지정하면, 호출된 FM 안에서 `RAISE`/`MESSAGE ... RAISING`으로 발생한 예외는 모두 OTHERS로 잡혀 `sy-subrc = 1`이 됩니다. 예외가 발생하지 않고 정상 종료되면 `sy-subrc = 0`입니다.

다만 선언되지 않은 예외는 발생할 수 없으므로 실제로는 FM 내부에서 예외 선언 없이 발생하는 경우(예: 클래스 기반 예외가 아닌 시스템 오류 등)만 해당되며, 선언이 없는 FM이라면 대부분 `sy-subrc = 0`입니다. 단, 잡히지 않는 런타임 오류(short dump)는 OTHERS로도 잡히지 않습니다.
