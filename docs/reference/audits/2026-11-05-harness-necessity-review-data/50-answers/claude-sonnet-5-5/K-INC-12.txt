글로벌 클래스 정의에 `FOR BEHAVIOR OF <루트 엔티티(BDEF 이름)>` 절이 반드시 있어야 합니다. 예: `CLASS lhc_travel DEFINITION INHERITING FROM cl_abap_behavior_handler`가 아니라, 글로벌 클래스는 `CLASS zbp_i_travel DEFINITION PUBLIC ABSTRACT FINAL FOR BEHAVIOR OF zi_travel.` 형태입니다.

이 절이 없으면 해당 클래스는 BDEF의 behavior pool로 인식되지 않아, BDEF에서 `implementation in class ... unique`로 지정해도 활성화 오류가 나고 로컬 핸들러/세이버 클래스(`lhc_`, `lsc_`)도 RAP 동작을 구현할 수 없습니다.
