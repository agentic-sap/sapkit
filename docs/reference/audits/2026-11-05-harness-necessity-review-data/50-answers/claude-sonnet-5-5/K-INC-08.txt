변환 exit이 걸린 필드를 CDS 뷰에 그대로 실으면, OData 서비스에서는 보통 **내부(저장) 형식이 그대로 노출**됩니다. 예를 들어 ALPHA exit 필드는 앞에 0이 붙은 `0000001234` 형태로, 날짜·단위(CUNIT 등)는 내부 값으로 나옵니다. CDS/ABAP SQL 계층은 conversion exit을 자동 적용하지 않기 때문입니다.

다만 Gateway/RAP 프레임워크가 DDIC 도메인의 exit 정보를 이용해 일부 필드에 변환을 적용하는 경우가 있어, 의도한 형식이 필요하면 CDS에서 직접 변환(예: `lpad`/`ltrim` 등)하거나 `@Semantics`·별도 표시용 필드로 처리하는 편이 안전합니다.
