마스터 테이블(예: MARA)의 키로 직접 이름을 읽지 말고, 텍스트 테이블(예: MAKT, 언어 키 SPRAS 포함)을 `SPRAS = SY-LANGU`로 조회하세요. 해당 언어 텍스트가 없을 때만 EN 등으로 폴백하면 영문 더미나 공란이 줄어듭니다.

F4 값테이블 구성에서는 텍스트 테이블 없이 마스터 테이블만 값테이블로 쓰는 것, SPRAS 조건 없이 모든 언어를 읽어 중복 행을 만드는 것, 언어를 `'E'`처럼 하드코딩하는 것을 피하세요.

기억에 의존한 일반 원칙이라, 구체적인 테이블 구성은 실제 시스템에서 확인이 필요합니다.
