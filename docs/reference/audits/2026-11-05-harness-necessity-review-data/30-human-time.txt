계수 규칙
  R1 행 = 분류가 하나로 떨어지는 최소 단위. 질문 묶음은 칸(차원·필드)마다 한 행(칸마다 분류가 다르다),
     승인·명시 멈춤·리뷰 왕복·제안은 자리마다 한 행. 「묶음 수」는 집계에 따로 적는다.
     ⇒ 20% 선의 분모는 이 행 수(= 분류 3종의 합)다. spec E-2 의 「자리」를 이 단위로 읽었다.
  R2 조건부 자리(분기·설정 누락·옵트인에서만 서는 자리)도 센다 — 조건 열에 적고, 집계에 「무조건 자리」를
     따로 낸다. 빠뜨리는 것보다 과잉 계수가 재분류하기 쉽다.
  R3 파내기 단계(interview-sweep)는 질문 수 상한이 없다(L156 「There is no cap」). 열거된 종류 10개
     (L93~110, 「a floor, not a ceiling」)를 종류당 한 행으로 세고 바닥(floor)으로 표시한다.
  R4 같은 멈춤이 여러 절에 적혀 있으면(예: 닫힌 일곱 ⑦ ↔ Phase 8 되읽기 불일치) 한 행으로 세고 줄 번호를
     모두 단다.
  R5 사람 시간이 호스트마다 다른 자리(리뷰 왕복·권한 선허용)는 행에 호스트를 적는다.
  R6 제외: 「진술이지 질문이 아니다」라고 문서가 명시한 자리(진행 한 줄 보고·HTML 안내 줄·마무리 제안) ·
     에이전트/리뷰어 내부 관문(「gate」가 기계 검사인 경우) · 멈춤 없이 끝나는 거절. 전부 J절에서 「멈추는
     자리 아님」으로 대조한다.

분류 규칙 (재분류 가능하도록 — 각 행의 근거가 이 중 어느 것인지 말한다)
  사용자만 답할 수 있음 — 비즈니스 사실·의미·범위·선호. 이 런의 문서·앞선 답·P0/P1 읽기 어느 것도 답을
     내지 못한다. 추천안이 붙어 있어도 「선택」이 선호이면 여기(패러다임·표시 모드·문서 형식 등).
  유도 가능 — 앞선 답·사용자 문서·브리프·KD/KS 원자·config·P1 읽기가 답을 낸다. 「내가 유도한 값을
     확인해 달라」는 자리(확인 재진술·커버리지 맵·지도 정정 초대·제안값 확인 화면)는 전부 여기.
     ※ 동의형 제안(지식·교훈·설정값 기억·권한 선허용·단계별 확인 옵트인) — 정보는 이미 손에 있고 절차
     자신의 논리가 기본값을 정하므로 여기로 분류하되 종류를 「제안(opt-in)」/「확인(옵트인)」으로 따로
     표시한다. 이 자리들이 서는 이유는 정보가 아니라 파일 쓰기·설정 변경 동의이므로, 감사가 따로 다룰 수
     있게 집계에 「동의형 제외」 수치를 병기한다(판정 줄은 사전 등록대로 전체 비율로만 낸다).
  안전 규칙상 필수 — CLAUDE.md 안전 규칙·AGENTS.md 가 사람 승인을 요구하는 자리: P2 실데이터 건별 승인 ·
     P3 쓰기 진입 전 설계 승인(approval-gates Gate A) · P4 이송 사람 소유(선택·배정·릴리스) · DEV 전용
     쓰기 · 되읽기 확인 없이 완료 금지 · 독립 리뷰 없이 완료 금지. 답이 유도 가능해도 규칙이 멈춤을
     요구하면 여기(재심 제외 — spec E-2).
