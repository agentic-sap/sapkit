판K — 하네스를 켠 비교 (harness-on comparison) 자료 폴더
=====================================================================

이 폴더는 2026-11-08 착수한 판K(D-160)의 **측정 자료 폴더**다. 판J 표본 60 · 코드 5과제를 「하네스 폴더(지식 팩 +
페르소나)를 읽을 수 있는」 조건으로 다시 응시한 원자료 · 표 · 레시피 · 카나리아 응답을 한 자리에 모은다. 판단(결론)은
여기 두지 않는다 — 결론은 판K 의 감사 문서와 결정 로그(D-번호)가 가진다. 여기에는 **측정한 것 · 관찰한 것**만 둔다.
판J 자료 폴더(../2026-11-05-harness-necessity-review-data/ · 이하 J-번호)의 README 를 승계하고, 아래만 더하거나 바꾼다.
판J 자료는 한 바이트도 고치지 않는다 — 판K 의 러너는 J-10 · J-11 을 그 자리에서 읽기만 한다.

이 폴더에 .md 파일을 두지 않는다 (판J 와 같은 이유)
------------------------------------------------
  공방 문서 게이트 scripts/check-wiki.mjs 가 docs/reference/**/*.md 를 고아 검출 분모로 잡는다. 이 폴더의 .md 는 위키
  어디에서도 링크되지 않으므로 게이트가 red 가 된다. 허용 확장자: .txt .json .csv .abap .mjs .ps1

비밀 · 식별 정보 금지 (판J 와 같음 + 판K 기계 검사)
------------------------------------------------
  이 폴더 어디에도 계정 · 컴퓨터 이름 · 호스트 · URL(아래 예외 밖) · SID · 클라이언트 · 사용자 ID · sap.env 값 · 세션 id ·
  레포 절대 경로 · 다른 프로젝트 · 프로파일 이름을 적지 않는다.
  기계 검사: node K-99-namecheck.mjs <이 폴더>  → 위반 0 이면 exit 0. 커밋 전마다 돌린다(D-160 「마감 게이트에 자료 폴더 전체의
  이름 검사」). 검사는 찾은 글자를 찍지 않고 범주 · 줄 번호 · 수만 찍는다. 음성시험: node K-99-namecheck.mjs --selftest
  (T0 결과 = K-02-canary/namecheck-selftest.txt).
  로컬 경로: 러너는 자료 폴더에 쓰는 글(실행 기록 · 재시도 사유 · 카나리아 응답 · 답안)에서 %TEMP% 와 홈 경로 조각을
  「%TEMP%」 · 「~」 로 바꿔 적는다. 답안은 그 조각만 바꾸고 바꾼 수를 이벤트 요약에 적는다(그 밖 글자는 무편집).
  원 이벤트 스트림(JSONL) · 무효 시도의 원응답 · Codex 임시 홈은 %TEMP%\sapkit-panK\ 아래에만 두고 커밋하지 않는다.

URL 예외 (판K 에서 더함)
------------------------
  하네스 폴더(커밋 4f12d678 의 interactive/core/knowledge · personas — 팩)의 본문에 **글자 그대로 있는** URL 은 답안 ·
  카나리아 응답에 나와도 된다(D-160 ⓪ 유효성 ④ — 모델이 팩을 읽고 옮긴 것). 그 밖의 URL 은 응시 시도를 무효로 만들고(러너),
  자료 파일에서는 <url> 로 가린다. namecheck 의 허용 목록도 팩 본문에서 읽어 만든다.
