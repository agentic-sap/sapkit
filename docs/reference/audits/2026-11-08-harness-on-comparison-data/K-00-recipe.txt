  Codex 명령 분류 (정본 — 분류가 애매하면 위반 · fail-closed)
    0. 셸 껍데기를 한 겹 벗긴다(그 껍데기 자체는 위반이 아니다):
         powershell : (?is)^"?(?:[^"\s]*[\\/])?(?:powershell|pwsh)(?:\.exe)?"?(?:\s+-(?!Command\b|c\b)[A-Za-z]+(?:\s+(?!-)[^\s-]\S*)?)*\s+-(?:Command|c)\s+(?<inner>.+)$
         bash       : (?is)^"?(?:[^"\s]*[\\/])?(?:bash|sh|zsh)(?:\.exe)?"?\s+-l?c\s+(?<inner>.+)$
         cmd        : (?is)^"?(?:[^"\s]*[\\/])?cmd(?:\.exe)?"?\s+/[cC]\s+(?<inner>.+)$
       inner 가 '…' 또는 "…" 로 통째 감싸였으면 한 겹 벗긴다.
    1. 따옴표 안을 지운 「맨 글」에서: 허용 리다이렉트만 먼저 지운다 — (?<![>\w])[0-9*]?>&[0-9]  ·  (?<![>\w])[0-9*]?>\s*(?:\$null|nul|/dev/null)(?![\w/])
       그 뒤 > 가 남으면 위반(write:redirect) · $( 나 ` 가 있으면 위반(ambiguous) · git 네트워크 (?i)(?<![\w-])git(\.exe)?\s+(clone|fetch|pull|push)(?![\w-]) 위반
    2. 맨 글을 && || | ; 줄바꿈으로 마디로 나눈다. 마디에 & 가 남으면 위반(exec: 호출 연산자 · 백그라운드).
       마디 머리 낱말(앞의 ( { @ 를 떼고 소문자 · .exe 떼고)이 아래 「읽기 머리」에 없으면 위반. 머리가 경로 꼴이면 위반.
       sed 는 -n 이 있고 -i 가 없을 때만 · find 는 -exec -execdir -delete -fprint -fprintf -fls -ok 가 없을 때만.
    3. 맨 글의 모든 낱말(공백 ( ) { } [ ] , ; | 로 자름 · 소문자 · .exe 뗌)이 아래 금지 낱말이면 위반.
    4. 원 명령(따옴표 포함)의 모든 낱말에서 따옴표와 -이름: 머리를 떼고, 플래그(-…)와 허용 리다이렉트를 빼고, 경로 꼴이면 ⑵ 로 잰다.
    읽기 머리 : cat type get-content gc ls dir get-childitem gci rg grep select-string sls findstr head tail sed find wc tree
                test-path resolve-path pwd get-location gl get-item gi select-object select sort-object sort measure-object measure
                where-object where ? foreach-object % format-table ft format-list fl out-string echo write-output write-host uniq
                cut nl split-path join-path get-filehash cd set-location sl pushd popd
